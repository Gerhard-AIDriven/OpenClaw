# Gmail Signature & Theme Setup

## Signature Setup

Your signature is ready in `signature.html`. Here's how to add it to Gmail:

### Steps:
1. Go to **Gmail** → **Settings** (gear icon, top right)
2. Click **Settings** (not just the dropdown)
3. Go to **Forwarding and POP/IMAP** tab
4. Scroll down to **Signature**
5. Click **Create new** and name it "AI Driven"
6. **Copy the HTML code from `signature.html`** and paste it into the signature box
7. Click **Save Changes** at the bottom

### What's included:
- ✅ AI Driven logo (60px height)
- ✅ Your name & title
- ✅ Email, website, phone
- ✅ Location (South Africa)
- ✅ Tagline: "Practical AI For Real Businesses"
- ✅ Brand colours: Gold (#f7931e) + Black + Charcoal

## Theme Setup (Optional)

Gmail has limited native theming. The easiest approach is to use Gmail's built-in themes:

### Steps:
1. Go to **Gmail Settings** (gear icon)
2. Go to **Display settings** tab
3. Scroll to **Theme**
4. Choose one of these:
   - **Light background** (closest to your white one-pager)
   - Then customize with custom CSS in a browser extension (advanced)

### For Full Control (Advanced):
If you want custom CSS theming, you'd need to use a browser extension like:
- **Stylus** (Chrome/Firefox)
- Paste the CSS from `gmail-theme.css`

But honestly, Gmail's built-in themes are limited. The signature is the bigger win visually.
