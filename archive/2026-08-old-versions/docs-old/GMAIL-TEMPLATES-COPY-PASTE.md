# Gmail Templates - Copy/Paste Ready

**Created:** 2026-08-17  
**Purpose:** Easy copy/paste templates for manual processing emails

---

## How to Use

### Option 1: Manual Copy (Fastest)
1. Open Gmail → Compose
2. Copy the **Subject** line from below
3. Paste into email subject field
4. Copy the **Body** from below
5. Paste into email body
6. Replace `[bracketed placeholders]` with actual values
7. Send!

### Option 2: Save as Gmail Template
1. Follow steps above to create email
2. Before sending: Click three dots ⋮ → **Templates** → **Save draft as template**
3. Name it (e.g., "DD - Manual Processing Ack")
4. Click Save
5. Now it's reusable forever!
