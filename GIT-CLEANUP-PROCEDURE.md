# Git Repository Cleanup Procedure

## 🎯 Purpose
Keep the Git repository lean and fast by preventing generated files from bloating the history.

## ⚠️ The Problem We Solved
- Generated reports (HTML/PDF/JSON) were adding thousands of lines to Git
- Cache files (databases, XML capabilities) were hundreds of MBs
- GitHub push was failing/hanging due to repo size
- History rewrite was needed to remove large files

## ✅ The Solution
1. **Comprehensive `.gitignore`** - Prevents tracking of generated files
2. **Local archive system** - `.git-ignored-archive/` stores reports locally
3. **Automated cleanup script** - One command before each push
4. **Retention policy** - Keep recent reports accessible, archive the rest

---


### What the Script Does
1. Creates timestamped archive folder: `.git-ignored-archive/reports/YYYY-MM-DD-HHMMSS/`
2. Moves all generated reports from:

   - `due-diligence-mvp/reports/`
   - `due-diligence-mvp/sample-reports/`
   - `aidriven-website/reports/`
3. Preserves reports locally (not lost, just not in Git)

## 🧹 Monthly Maintenance

Once a month, clean up old archives:

```powershell
# Delete archives older than 90 days
$cutoff = (Get-Date).AddDays(-90)
Get-ChildItem ".git-ignored-archive\reports" -Directory | 
  Where-Object { $_.CreationTime -lt $cutoff } | 
  Remove-Item -Recurse -Force
```

Or manually browse and delete old timestamp folders.

## 🚨 Emergency Cleanup

If Git push fails due to size again:

### Step 1: Check what's large
```powershell
git count-objects -vH
```

### Step 2: Clean untracked files
```powershell
git clean -fdx
```

### Step 3: Verify clean state
```powershell
git status
# Should show only source code files
```

### Step 4: If still bloated, run aggressive GC
```powershell
git gc --aggressive --prune=now
git push origin master --force
```

## 🎯 Golden Rules

1. **If a script generates it → Archive it, don't Git it**
2. **Hand-written source code → Git it**
3. **Configuration files → Git it**
4. **Documentation → Git it**
5. **Test results/reports → Archive locally**

### Quick Decision Tree
```
Is it hand-written source code?
├─ YES → Add to Git
└─ NO → Is it generated by a script/tool?
    ├─ YES → Archive locally (not Git)
    └─ NO → Is it configuration/documentation?
        ├─ YES → Add to Git
        └─ NO → Probably temporary, delete or archive
```

## 🔧 Troubleshooting

### "Git push still slow/large"
Check for unignored files:
```powershell
git status --short
# Look for any .html, .json, .db, .xml files
# Add them to .gitignore if they're generated
```

### "Accidentally committed a large file"
Remove from history:
```powershell
git filter-branch --force --index-filter 'git rm --cached --ignore-unmatch PATH_TO_FILE' --prune-empty --tag-name-filter cat -- --all
git push origin master --force
```
