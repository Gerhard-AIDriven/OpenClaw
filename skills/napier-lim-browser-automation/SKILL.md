# Napier LIM Browser Automation Skill

## Description
This skill automates the submission of Land Information Memorandum (LIM) applications to the Napier City Council online portal. It takes a structured JSON payload (typically generated by the `napier-lim-submission` skill) and drives a browser session to fill out the multi-step web form, stopping precisely at the "Make Payment" page for manual user completion.

## Prerequisites
- A valid `lim_request_confirmation.json` file for the target property.
- Access to the Napier City Council LIM portal URL.
- Browser automation capabilities enabled in the environment.

## Workflow Steps

### Step 1: Initialization
- Load the `lim_request_confirmation.json` file.
- Extract key data: Property Address, Legal Description, Applicant Details, Fee Type.
- Launch browser session targeting the Napier City Council LIM application URL.

### Step 2: Property Selection (Step 1 of Portal)
- **Action:** Locate the search input field.
- **Input:** Enter the `physical_address.street_number` + `physical_address.street_name` (e.g., "49 Wai Whatu Street").
- **Action:** Click "Search".
- **Action:** Wait for results, select the matching property (verify against `legal_description` if visible).
- **Action:** Click "Start My Application >>".

### Step 3: Contact Details (Step 2 of Portal)
- **Applicant Type:** Select Radio Button "I am applying as an individual" (or "Business" if specified).
- **Name:** Fill `applicant_details.first_name` and `applicant_details.last_name`.
- **Delivery Method:** Check the "Email" checkbox (matches `applicant_details.delivery_method`).
- **Address:** Fill fields:
  - Number/Street: `applicant_details.billing_address.street`
  - Suburb: `applicant_details.billing_address.suburb`
  - City: `applicant_details.billing_address.city`
  - Postcode: `applicant_details.billing_address.postcode`
  - Country: `applicant_details.billing_address.country`
- **Contact:** Fill `applicant_details.contact_info.phone` and `applicant_details.contact_info.email` (and confirm email).
- **Action:** Click "Continue >>".

### Step 4: Options (Step 3 of Portal)
- **Fee Selection:** Select Radio Button matching `application_options.fee_type` (e.g., "$420.00 Residential / Rural Residential").
- **Terms & Conditions:** Locate and **Check** the Terms & Conditions acceptance checkbox (Mandatory).
- **Action:** Click "Continue >>".

### Step 5: Summary (Step 4 of Portal)
- **Verification:** The portal displays a summary. The script performs a passive wait to allow visual verification if running in headed mode.
- **Action:** Click "Continue >>" (or "Submit" depending on exact label) to proceed to payment.

### Step 6: Payment Halt (Step 5 of Portal)
- **Target State:** The browser lands on the "Make Payment" page showing the total due (e.g., "$420.00").
- **Action:** **STOP AUTOMATION.**
- **Notification:** Inform the user that the form is complete and ready for manual payment processing.
- **Safety:** Do **NOT** click "Proceed To Credit Card Payment" automatically.

## Error Handling
- **Property Not Found:** If the search in Step 2 yields no results, abort and report the address mismatch.
- **Validation Errors:** If the portal highlights missing fields, abort and report the specific missing field labels.
- **Timeouts:** Apply standard browser automation timeouts (30s per step).

## Success Criteria
- All form fields across Steps 1–4 are filled accurately according to the JSON.
- The session successfully reaches the "Make Payment" page.
- No payment action is taken automatically.
