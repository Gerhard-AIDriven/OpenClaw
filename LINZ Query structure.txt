LINZ Data Service - Vector Query Structure (WFS 2.0 / JSON)

Base URL: https://data.linz.govt.nz/services/query/v1/vector.json

Required Parameters:
- key: [API_KEY] (Authentication)
- layer: [LAYER_ID] (The specific data layer, e.g., 112668 for Gabrielle Flood)
- x: [LONGITUDE] (Decimal degrees)
- y: [LATITUDE] (Decimal degrees)

Optional Parameters:
- radius: [METRES] (Search radius around the point, default 5000)
- max_results: [NUMBER] (Limit the number of features returned)
- geometry: [true/false] (Whether to return the GeoJSON geometry)
- with_field_names: [true/false] (Include field names in the response)

Example Request:
https://data.linz.govt.nz/services/query/v1/vector.json?key=API_KEY&layer=112668&x=176.9120&y=-39.4928&max_results=5&radius=5000&geometry=false&with_field_names=true

Response Structure:
{
  "vectorQuery": {
    "layers": {
      "[LAYER_ID]": {
        "field_names": ["field1", "field2", ...],
        "features": [
          {
            "properties": {
              "field1": "value",
              "field2": "value"
            },
            "distance": 123.45
          }
        ]
      }
    }
  }
}
